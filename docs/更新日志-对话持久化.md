# RAG Agent 对话持久化 - 开发笔记

## 背景

### 问题

原来的 `RagAgentService` 使用 `MemorySaver()` 作为 LangGraph 的检查点存储，对话历史仅保存在**进程内存**中：

```python
# rag_agent_service.py (修改前)
self.checkpointer = MemorySaver()  # ❌ 纯内存存储，重启即丢失
```

这意味着：
- 应用重启后，所有对话历史全部清空
- 用户无法在重启后继续之前的对话
- `GET /api/chat/session/{session_id}` 只能获取当前进程内的会话数据

而 AIOps 服务已经通过 `AbstractStorageEngine` 接口实现了完整的状态持久化（保存到 SQLite/PostgreSQL），Chat 对话却没有。

### 解决方案

**复用现有的 `AbstractStorageEngine`**，在 `RagAgentService` 中实现与 AIOps 风格一致的持久化模式。

---

## 架构设计

### 改造前后对比

| 组件 | 改造前 | 改造后 |
|------|--------|--------|
| AIOps 会话 | `AbstractStorageEngine` → SQLite ✅ | 不变 ✅ |
| Chat 对话 | `MemorySaver`（仅内存）❌ | `MemorySaver` + `AbstractStorageEngine` → SQLite ✅ |

### 数据隔离策略

使用 `chat:{session_id}` 作为 Chat 会话的存储 key，与 AIOps 的 `{session_id}` 隔离：

```
SQLite sessions 表:
┌──────────────────────┬──────────────────────────────────┐
│ thread_id            │ state_json                       │
├──────────────────────┼──────────────────────────────────┤
│ default              │ {"input":"...", "plan":[...]}     │  ← AIOps
│ chat:session-123     │ {"messages":[...]}                │  ← Chat
│ chat:session-456     │ {"messages":[...]}                │  ← Chat
└──────────────────────┴──────────────────────────────────┘
```

### 消息序列化格式

将 LangChain `BaseMessage` 对象序列化为纯 JSON 字典（非 pickle），确保跨版本兼容：

```json
{
  "messages": [
    {"type": "human", "content": "查询 data-sync-service 的日志", "timestamp": "2026-06-21T14:30:00"},
    {"type": "tool", "content": "查询结果...", "name": "search_log", "tool_call_id": "call_xxx", "timestamp": "..."},
    {"type": "ai", "content": "查到 3 条 ERROR 日志...", "timestamp": "..."}
  ]
}
```

支持的消息类型：

| LangChain 类型 | 序列化 type | 说明 |
|---------------|------------|------|
| `HumanMessage` | `human` | 用户消息 |
| `AIMessage` | `ai` | AI 回复 |
| `SystemMessage` | - | **过滤掉，不持久化**（每次动态构建） |
| `ToolMessage` | `tool` | 工具调用结果（额外保存 name 和 tool_call_id） |

### MemorySaver 的保留

**保留 `MemorySaver`**，不删除。原因：

- `create_agent` 依赖它进行单次请求内的状态跟踪（工具调用循环等）
- 但**不再依赖它来恢复跨请求的历史消息**
- 每次请求都从 SQLite 加载完整历史，手动传入 Agent

```
请求开始
  ↓
从 SQLite 加载历史消息
  ↓
history + SystemPrompt + 新问题 → Agent
  ↓
Agent 执行（MemorySaver 管理单次请求状态）
  ↓
提取对话消息 → 序列化 → 保存到 SQLite
  ↓
返回答案
```

#### 1.3 新增辅助方法

**`_chat_key(session_id)`** - 生成带前缀的存储 key：

```python
def _chat_key(self, session_id: str) -> str:
    return f"chat:{session_id}"
```

**`_serialize_messages(messages)`** - 序列化消息列表：

```python
def _serialize_messages(self, messages: List[BaseMessage]) -> List[Dict[str, Any]]:
    serialized = []
    for msg in messages:
        if isinstance(msg, SystemMessage):
            continue  # 系统提示不持久化

        msg_dict = {
            "content": msg.content,
            "timestamp": datetime.now().isoformat(),
        }

        if isinstance(msg, HumanMessage):
            msg_dict["type"] = "human"
        elif isinstance(msg, AIMessage):
            msg_dict["type"] = "ai"
        elif isinstance(msg, ToolMessage):
            msg_dict["type"] = "tool"
            msg_dict["name"] = getattr(msg, 'name', '')
            msg_dict["tool_call_id"] = getattr(msg, 'tool_call_id', '')

        serialized.append(msg_dict)
    return serialized
```

**`_deserialize_messages(messages_data)`** - 反序列化消息列表：

```python
def _deserialize_messages(self, messages_data: List[Dict[str, Any]]) -> List[BaseMessage]:
    messages = []
    for msg in messages_data:
        msg_type = msg.get("type", "unknown")
        content = msg.get("content", "")

        if msg_type == "human":
            messages.append(HumanMessage(content=content))
        elif msg_type == "ai":
            messages.append(AIMessage(content=content))
        elif msg_type == "tool":
            messages.append(ToolMessage(
                content=content,
                name=msg.get("name", ""),
                tool_call_id=msg.get("tool_call_id", ""),
            ))
    return messages
```

#### 1.4 改造 `query()` 方法

在每次请求开始时从 SQLite 恢复历史，结束时持久化：

```python
async def query(self, question: str, session_id: str) -> str:
    # 1. 从持久化存储恢复历史消息
    saved_state = await self.storage.get_state(self._chat_key(session_id))
    history_messages = self._deserialize_messages(
        saved_state["messages"]
    ) if saved_state and "messages" in saved_state else []

    # 2. 构建完整消息列表（历史 + 系统提示 + 新问题）
    messages = history_messages + [
        SystemMessage(content=self.system_prompt),
        HumanMessage(content=question)
    ]

    # 3. 执行 Agent
    result = await self.agent.ainvoke({"messages": messages}, config=config_dict)

    # 4. 持久化：提取对话消息（过滤系统提示）
    chat_messages = [m for m in result["messages"] if not isinstance(m, SystemMessage)]
    await self.storage.save_state(
        self._chat_key(session_id),
        {"messages": self._serialize_messages(chat_messages)}
    )
```

#### 1.5 改造 `query_stream()` 方法

流式请求结束后从 `MemorySaver` 获取最终状态并持久化：

```python
async def query_stream(self, question: str, session_id: str):
    # 1. 从持久化存储恢复历史消息（同 query）

    # 2. 流式执行
    async for token, metadata in self.agent.astream(...):
        yield ...

    # 3. 流结束后持久化
    final_state = self.checkpointer.get(config_dict)
    if final_state:
        checkpoint_messages = final_state.checkpoint["channel_values"]["messages"]
        chat_messages = [m for m in checkpoint_messages if not isinstance(m, SystemMessage)]
        await self.storage.save_state(
            self._chat_key(session_id),
            {"messages": self._serialize_messages(chat_messages)}
        )
```

#### 1.6 改造 `get_session_history()` 和 `clear_session()`

两个方法改为 async，从 SQLite 读取/删除：

```python
async def get_session_history(self, session_id: str) -> list:
    saved_state = await self.storage.get_state(self._chat_key(session_id))
    return saved_state["messages"] if saved_state else []

async def clear_session(self, session_id: str) -> bool:
    self.checkpointer.delete_thread(session_id)  # 清除内存
    await self.storage.delete_state(self._chat_key(session_id))  # 清除持久化
    return True
```

## 注意事项

1. **SystemMessage 不持久化**：系统提示词每次请求动态构建（包含可用工具列表），因此不保存到数据库
2. **key 前缀隔离**：Chat 使用 `chat:` 前缀，AIOps 使用原始 session_id，互不干扰
3. **MemorySaver 保留**：`create_agent` 内部依赖它进行工具调用循环的状态管理，不能删除
4. **流式持久化容错**：流式对话的持久化失败不影响对话结果（catch 异常并 warning）
5. **历史消息全量加载**：当前实现每次请求加载全部历史消息，对于超长对话可能需要结合上下文压缩功能
