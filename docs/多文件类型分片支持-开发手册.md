# 多文件类型分片支持 -- 开发手册

> **版本**: v1.2.2
> **日期**: 2026-06-06
> **目的**: 将知识库上传向量化从 md/txt 扩展到 md/txt/pdf/docx

---

## 1. 背景与目标

### 改造前
- 知识库文件上传仅支持 .md 和 .txt 两种格式
- 文件读取使用 path.read_text(encoding="utf-8")，只能读纯文本
- 分片逻辑硬编码：split_document() 只判断是否为 .md

### 改造后
- 支持 4 种文件类型：md、txt、pdf、docx
- 新增统一提取层 extract_text()：根据文件扩展名自动选择提取方式
- 扩展分片分发层 split_document()：按扩展名路由到对应分片器
- PDF/Word 提取为纯文本后复用已有的递归字符分片器，最大化代码复用

---

## 2. 整体架构

```
                      用户上传文件
                            |
                            v
                  file.py (扩展名白名单校验)
                            |
                            v
                  vector_index_service.py
                    index_single_file()
                            |
                            v
                  document_splitter_service.py
                      extract_text()         <-- NEW: 统一提取层
                     /    |     |     \
                   .md   .txt  .pdf  .docx
                    |     |     |      |
                 read   read  PyPDF  Docx2txt
                _text   _text Loader  Loader
                    |     |     |      |
                    v     v     v      v
                    纯文本内容 (统一为 str)
                            |
                            v
                      split_document()       <-- 扩展: 新的分发逻辑
                       /          \
                     .md         .txt/.pdf/.docx
                      |               |
                split_markdown    split_text
                (三阶段分片)    (递归字符分片)
                      |               |
                      v               v
                  List[Document] 分片列表
                            |
                            v
                  vector_store_manager
                    add_documents()
                            |
                            v
                    向量化 -> Milvus
```

核心设计原则：提取与分片分离。所有文件先提取为统一文本，再按类型选择分片策略。

### 3.2 document_splitter_service.py -- 核心改造

本次改动最核心的文件，包括以下子改动：

#### A. 新增导入

```python
from langchain_community.document_loaders import Docx2txtLoader, PyPDFLoader
```

#### B. 新增 SUPPORTED_EXTENSIONS 类常量

```python
SUPPORTED_EXTENSIONS = {
    ".txt": "纯文本",
    ".md": "Markdown",
    ".pdf": "PDF 文档",
    ".docx": "Word 文档",
}
```

这个字典有两个作用：
1. 让 extract_text() 快速判断文件类型是否支持
2. 作为文档化的类型注册表，新增类型只需加一行

#### C. 新增 extract_text() -- 统一提取入口

extract_text(file_path) 是对外的唯一入口。根据扩展名自动分派到内部的
_extract_text_from_file()。

#### D. 新增 _extract_pdf() -- PDF 文本提取

```python
def _extract_pdf(self, file_path: str) -> str:
    """使用 langchain_community 的 PyPDFLoader 逐页读取 PDF 文本流"""
    loader = PyPDFLoader(file_path)
    pages = loader.load()
    # 拼接所有页面，页间加双换行
    texts = []
    for page in pages:
        page_text = page.page_content.strip()
        if page_text:
            texts.append(page_text)
    return "\n\n".join(texts)
```

关键点：
- PyPDFLoader.load() 返回 List[Document]，每个 Document 对应一个 PDF 页面
- 页间用双换行拼接，便于递归分割器在页面边界自然切分

#### E. 新增 _extract_docx() -- Word 文本提取

```python
def _extract_docx(self, file_path: str) -> str:
    """使用 langchain_community 的 Docx2txtLoader 提取纯文本"""
    loader = Docx2txtLoader(file_path)
    docs = loader.load()
    return docs[0].page_content if docs else ''
```

关键点：
- Docx2txtLoader.load() 通常返回 1 个 Document，page_content 即为全文
- 底层 docx2txt 库解析 docx 的 XML 结构，提取纯文本（不含样式/表格/图片）

#### F. 扩展 split_document() -- 分片分发逻辑

```python
def split_document(self, content: str, file_path: str = '') -> List[Document]:
    ext = Path(file_path).suffix.lower()

    if ext == ".md":
        return self.split_markdown(content, file_path)
    elif ext in (".txt", ".pdf", ".docx"):
        return self.split_text(content, file_path)
    else:
        logger.warning(f"未知文件类型 {ext}")
        return self.split_text(content, file_path)
```

改动点：原来只有 if .md -> split_markdown else -> split_text，
现在明确列出 .txt/.pdf/.docx 走 split_text，外加 else 兜底。

### 3.4 vector_index_service.py -- 索引流程适配

***改动 1 -- index_directory() glob 扩展***:

```python
# 旧
files = list(dir_path.glob("*.txt")) + list(dir_path.glob("*.md"))

# 新
files = (
    list(dir_path.glob("*.txt"))
    + list(dir_path.glob("*.md"))
    + list(dir_path.glob("*.pdf"))
    + list(dir_path.glob("*.docx"))
)
```

***改动 2 -- index_single_file() 文件读取改造***:

```python
# 旧: 只能读 UTF-8 纯文本
content = path.read_text(encoding="utf-8")

# 新: 通过 splitter 服务统一提取
content = document_splitter_service.extract_text(str(path))
```

为什么要改：path.read_text() 无法处理 PDF/DOCX 这类二进制文件。
改为调用 extract_text() 后，所有文件类型的文本提取逻辑都集中在 splitter 服务中管理。

## 4. 各文件类型分片原理

### 4.1 Markdown (.md) -- 三阶段结构感知分片

```
原始 Markdown
    |
    v
[阶段1] MarkdownHeaderTextSplitter
    按 H1(#) 和 H2(##) 标题切分
            |
            v
[阶段2] RecursiveCharacterTextSplitter
    chunk_size=1600, overlap=100
    按 \n\n -> \n -> 。 -> ， 优先级递归再切分
            |
            v
[阶段3] _merge_small_chunks(min_size=300)
    合并 < 300 字符的碎片到相邻片段
            |
            v
    List[Document] (每个 chunk 约 300-1600 字符)
```

为什么用这种方式：
- 阶段 1 按标题切分，保留文档的章节结构信息，让检索结果更精准
- 阶段 2 防止单个章节过长导致向量表示信息稀释
- 阶段 3 防止过度碎片化导致缺少上下文

### 4.2 纯文本 (.txt) -- 递归字符分片

```
原始文本
    |
    v
RecursiveCharacterTextSplitter
    chunk_size=1600, overlap=100
    按 \n\n -> \n -> 。 -> ， 优先级递归切分
            |
            v
    List[Document] (每个 chunk 约 800-1600 字符)
```

### 4.3 PDF (.pdf) -- 逐页提取 + 递归分片

```
PDF 二进制文件
    |
    v
PyPDFLoader.load()
    底层调用 pypdf 逐页读取文本流
    每页 -> 1 个 Document
            |
            v
    拼接: \n\n.join(所有页文本)
            |
            v
RecursiveCharacterTextSplitter (同 .txt)
    chunk_size=1600, overlap=100
            |
            v
    List[Document]
```

设计考量：
- 页间加双换行作为自然段落分隔，递归分割器会优先在页边界切分
- PyPDFLoader 只提取文本流，不识别图片/表格中的文字
- 对于扫描版 PDF（纯图片），PyPDFLoader 提取为空

### 4.4 Word (.docx) -- 纯文本提取 + 递归分片

```
.docx 文件
    |
    v
Docx2txtLoader.load()
    底层调用 docx2txt 解析 XML 结构
    提取纯文本 (不含样式/表格/图片)
            |
            v
    纯文本 (1 个 Document 的 page_content)
            |
            v
RecursiveCharacterTextSplitter (同 .txt)
    chunk_size=1600, overlap=100
            |
            v
    List[Document]
```

## 5. 如何扩展新文件类型

如果未来需要支持更多文件类型（如 .csv、.html、.pptx），只需改 2 个地方：

### Step 1: 在 document_splitter_service.py 注册

```python
# 1. 添加扩展名映射
SUPPORTED_EXTENSIONS = {
    # ... 已有 ...
    ".html": "HTML 网页",
    ".csv": "CSV 表格",
}

# 2. 添加提取方法
def _extract_html(self, file_path: str) -> str:
    from langchain_community.document_loaders import UnstructuredHTMLLoader
    loader = UnstructuredHTMLLoader(file_path)
    docs = loader.load()
    return docs[0].page_content if docs else ''

# 3. 在 _extract_text_from_file 中增加分支
elif ext == ".html":
    return self._extract_html(file_path)

# 4. 可选: 如果新类型需要特殊分片策略，在 split_document 中添加
elif ext == ".html":
    return self.split_html(content, file_path)
```

### Step 2: 更新白名单

```python
# file.py
ALLOWED_EXTENSIONS = ["txt", "md", "pdf", "docx", "html", "csv"]

# vector_index_service.py index_directory()
# 添加 list(dir_path.glob('*.html')) + list(dir_path.glob('*.csv'))
```

注意：不需要改 vector_store_manager.py、vector_embedding_service.py、
milvus_client.py -- 它们是类型无关的。

## 6. 完整调用链路 (以 PDF 上传为例)

```
1. POST /upload  (file.py)
   +-- 校验: 扩展名 pdf in ALLOWED_EXTENSIONS
   +-- 保存: uploads/故障分析.pdf (二进制写入)
   +-- 调用: vector_index_service.index_single_file(...)

2. VectorIndexService.index_single_file()
   +-- 读取: document_splitter_service.extract_text(file_path)
   |   +-- _extract_text_from_file() -> ext==".pdf"
   |       +-- _extract_pdf() -> PyPDFLoader.load()
   |           +-- 返回: "第一页内容\n\n第二页内容\n\n第三页内容"
   |
   +-- 删除旧数据: vector_store_manager.delete_by_source(normalized_path)
   |
   +-- 分割: document_splitter_service.split_document(content, file_path)
   |   +-- split_document() -> ext=="pdf"
   |       +-- split_text(content, file_path)
   |           +-- RecursiveCharacterTextSplitter: 1600 char, 100 overlap
   |           +-- 返回: [Doc1, Doc2, Doc3, ...]
   |
   +-- 存储: vector_store_manager.add_documents(documents)
       +-- 自动向量化: DashScope text-embedding-v4
       +-- 写入 Milvus biz collection
```
