# 分流标签

技能体系使用五个标准分流角色。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 技能中的角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待上报人提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整说明，agent 可开工 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如"应用 AFK-ready 分流标签"）时，请使用此表中对应的标签字符串。

如果实际使用的标签名不同，可修改右列内容以匹配。
